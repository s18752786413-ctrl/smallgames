# 厅内互动游戏网页小程序

当前网页小程序包含“拉新互动小游戏”“追分互动小游戏”“双人默契猜词挑战”“才艺考核”和“库洛米刮刮乐”，可从左侧游戏菜单切换。

GitHub Pages 发布地址：<https://s18752786413-ctrl.github.io/smallgames/>

## 一、游戏规则

- 新人完成交流：每人加2分。
- 新人完成支持：每人加10分。
- 总积分计算公式：`2 × 交流人数 + 10 × 支持人数`。
- 本轮总积分最低的宝子接受惩罚；出现并列最低时，网页会同时提示并列人员。

## 二、网页功能

- 采用16:9横屏界面，适合直播投屏或电脑横屏使用。
- 四个游戏已统一采用手机直播投屏大字版：按16:9画面缩至约390像素手机宽度后的可读性设计，核心正文在源画面采用约28—40px，关键分数采用约60—90px，并隐藏非必要英文小字。
- 页面采用固定1920×1080画布和固定像素字号；调整浏览器缩放时整张页面按同一比例变化，文字不会再单独随窗口宽度变化。
- 左侧为游戏选择区；选择“拉新互动”后菜单自动收起，主界面可通过“选择游戏”按钮重新打开，后续可继续增加其他游戏。
- 麦位采用动态添加方式，默认显示1—3麦，可依次增加到8麦或从末尾减少；未添加的麦位不显示。
- 页面保持16:9横屏比例，当前已添加的拍档行会在计分区内自动等高、等距铺开。
- 每个已显示麦位均可手动填写拍档名、交流人数和支持人数。
- 交流人数和支持人数既可直接输入，也可点击加减按钮调整。
- 总积分自动计算，最低分人员自动高亮并在右侧显示。
- 右侧提供可自定义分钟和秒数的倒计时，支持开始、暂停、继续和重置，归零后显示“时间到”。
- 同一台设备会自动保存当前填写内容，网页刷新后仍可继续记录。
- “重开一局”会在二次确认后清空全部拍档名和积分。

## 四、使用说明

打开已发布网页即可使用。计分记录保存在当前浏览器所在设备，不会自动同步到其他电脑或手机；如果需要多人或多设备同步，后续需增加账号及云端记录功能。

源码保存在GitHub仓库 `s18752786413-ctrl/smallgames`。修改并提交到 `main` 分支后，GitHub Actions会自动重新构建和发布网页。

## 五、追分互动小游戏

- 总分计算公式：`普通分数＋加速分数×2`。
- 支持手动输入普通分数、加速分数和加速工具。
- 建议互动时长为50分钟，倒计时可自行修改。
- 跑得最慢，即总分最低的小伙伴接受惩罚。
- 详细说明见：[《追分互动小游戏介绍》](../追分互动游戏/追分互动小游戏介绍.md)。

## 六、双人默契猜词挑战

- 独立黑金舞台风格，面向游客展示。
- 倒计时时长可自行设置，支持开始、暂停、继续和重置。
- 可设置每次调整的秒数，并在计时过程中随时增加或减少剩余时长。
- 页面展示“支持类”和“猛踩类”互动规则。
- 详细说明见：[《双人默契猜词挑战介绍》](../双人默契猜词挑战/双人默契猜词挑战介绍.md)。

## 七、才艺考核

- 独立粉金舞台视觉风格，支持1—8位选手动态增减。
- 每位选手可填写主播名和人气分，1000分为满条，分数可继续累计。
- 页面右侧实时呈现人气才艺冠军、亚军和季军。
- 页面展示功底路线与人气路线介绍。
- 详细说明见：[《才艺考核游戏介绍》](../才艺考核/才艺考核游戏介绍.md)。

## 八、库洛米刮刮乐

- 从用户自有飞书网页迁移，保留18张刮卡及原始结果内容。
- 支持鼠标或触屏按住刮开、已刮数量统计、全部刮开和重新开始。
- 支持紫粉、紫色、蓝白和绿白四套主题。
- 顶部规则和18项结果均可编辑，修改内容自动保存在当前浏览器。
- 详细说明见：[《库洛米刮刮乐游戏介绍》](../库洛米刮刮乐/库洛米刮刮乐游戏介绍.md)。
